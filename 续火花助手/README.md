# 抖音续火花助手（桌面版）

在电脑上自动“续火花”：扫码登录抖音网页版 -> 抓取好友会话并识别火花 -> 选择好友按设定时间自动发一条私信，保持火花不断。

> `inject/` 下的自动化脚本起家于 Android 端「夜航小子·抖音续火花」APK 中解出的纯 DOM 脚本，桥接层由本项目用 Electron 重写（window.AndroidBridge = 桌面宿主转发），脚本在桌面端持续维护适配。

## 两种形态

| 形态 | 目录 | 适用 |
|---|---|---|
| 开发/调试版 | 本工程（需 node_modules/electron） | 自己开发调试 |
| **免安装绿色版（分享用）** | 抖音续火花助手-免安装版-vX.Y.Z/ | 解压即用，朋友免装依赖 |

## 免安装绿色版使用

1. 把 抖音续火花助手-免安装版-vX.Y.Z.7z 发给朋友；解压后双击 启动续火花助手.bat。
2. 点「打开抖音页 / 刷新二维码」→ 手机抖音扫码登录（登录态保存在本机，下次免登录）。
3. 点「读取好友列表」→ 勾选要续火花的好友 → 填消息。
4. 立即续火花 / 设置每日自动（窗口开着到点跑）/ 生成计划任务（每天到点自动执行一次并退出）。

个人数据（登录态 / 待选好友 / 日志）存在每台电脑的 %APPDATA%\douyin-xuhuohua-helper 下，互不干扰。
打不开/出问题时看 %APPDATA%\douyin-xuhuohua-helper\data\logs\crash.log 排查。

## 重新打包（换版本后）

先保证 node_modules/electron 已装好（安装依赖.bat），然后：

    node scripts/rebuild-unpacked.js
    把 dist/win-unpacked 复制/改名为「抖音续火花助手-免安装版-vX.Y.Z/」（置于工程根目录）
    用 7-Zip 把该目录压成同名 .7z 交付（磁盘只保留带版本号的当前版目录与 .7z，旧版随发布清理）

## 开发版使用步骤

1. 双击「安装依赖.bat」（首次）。
2. 双击「启动续火花助手.bat」打开主界面。
3. 扫码登录 -> 读取好友列表 -> 勾选 -> 立即/定时。

## 命令行（计划任务用）

启动续火花助手.bat --auto：自动模式——免界面登录 -> 读取好友 -> 发消息 -> 写日志 -> 退出。

## 注意 / 风险

- 抖音网页版 DOM 频繁改版需维护选择器（脚本已多套兜底，失败只报错不中断）。
- 目标按昵称精确匹配，重名/置顶变化可能进错会话，发送前先核对。
- 账号自动化操作，只给自己认识的朋友续火花；请勿滥用。
