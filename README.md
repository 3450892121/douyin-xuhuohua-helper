# 抖音续火花助手（桌面版）

在电脑上自动「续火花」：扫码登录抖音网页版 → 自动抓取好友会话列表并识别火花 → 手动或按设定时间给勾选的好友发一条私信，让火花保持不断。

> 本工具仅供个人给自己认识的朋友续火花使用，请勿滥用或用于骚扰他人。

## 功能

- **多账号**：每个账号独立窗口 / 独立登录态 / 独立配置与定时，账号间切换互不串号；发送全局串行，避免同时操作。
- **好友列表**：自动滚动全量抓取会话，识别「有没有火花」（🔥 标记），昵称 + 头像去重，按账号磁盘缓存（切换 / 重启不丢）。
- **发送**：手动立即发、每日定时、好友独立定时、双时段兜底补发；可开关拟人化（随机文案 / 随机间隔）；跳过今天已发的；失败自动重试；防发错人（真重名 / 无法判定时宁可停发也不猜）。
- **定时两级**：程序常驻（窗口 / 托盘）用内置定时器；程序退出时用 Windows 计划任务 `--auto` 兜底。
- **网络模式**：一直联网（默认）/ 续完自动断网（到点前自动恢复）。
- **通知**：手写 SMTP 邮件（发送失败 / 登录失效提醒），零第三方依赖。
- **本地优先**：不做任何云端服务；登录态、好友、配置、日志全部只存本机 `%APPDATA%\douyin-xuhuohua-helper`，不上传任何服务器。

## 下载

免安装版（Windows x64）见 [Releases](https://github.com/3450892121/douyin-xuhuohua-helper/releases/latest)：下载 `.7z` 完整解压到任意目录，双击「启动续火花助手.bat」即可使用，无需安装 Node 或任何依赖。

## 使用（免安装版）

1. 解压后双击「启动续火花助手.bat」（或直接双击 `XHHelper.exe`）。
2. 点「打开抖音页 / 刷新二维码」→ 用手机抖音扫码登录（登录态只保存在本机，下次免登录）。
3. 点「读取好友列表」→ 勾选要续火花的好友 → 填好发送内容。
4. 点「立即续火花」，或设置每日自动 / 生成计划任务。

更细的使用说明（多账号、拟人化设置、开机自启、隐私说明等）见 [`续火花助手/使用手册.txt`](续火花助手/使用手册.txt)。

## 开发

要求：Windows + Node.js（自带 npm）。首次 `npm install` 需要下载 Electron 二进制（约 100MB）。

```bat
cd 续火花助手
npm install       :: 国内网络可双击「安装依赖.bat」，走 npmmirror 镜像
npm start         :: 开发模式启动
npm run check     :: 语法检查（node --check 全部 JS）
npm test          :: 单元测试（node:test，无需 Electron；覆盖好友去重/防发错人裁决/定时次序/配置迁移/桥接闸门）
```

打包免安装版：

```bat
cd 续火花助手
node scripts/rebuild-unpacked.js   :: 产出 dist/win-unpacked，自动内嵌 exe 图标并做运行时文件自检
```

## 项目结构

- `续火花助手/` — 应用主体
  - `main.js` — 主进程：双窗口管理、IPC 桥接、好友解析归一化、发送串行队列、定时调度、计划任务、配置持久化、托盘 / 开机自启
  - `preload-*.js` — 主界面 / 抖音窗口的 contextBridge 桥
  - `inject/` — 注入抖音页的自动化脚本（登录检测 / 二维码 / 列表滚动抓取 / 单次发送 / AndroidBridge 模拟）
  - `ui/` — 主界面（原生 HTML/CSS/JS，无框架）
  - `lib/notify.js` — 手写 SMTP 邮件客户端（零依赖）
  - `scripts/` — 打包、运行时文件自检、图标工具
  - `test/` — 单元测试（`npm test`，纯函数与历史回归用例）

## 数据与隐私

- 所有个人数据只保存在本机：`%APPDATA%\douyin-xuhuohua-helper`（开发态为 `续火花助手/data/`），包含登录态、好友缓存、发送记录与日志。
- 应用不访问、不读取系统浏览器的任何数据；登录只在本应用自己的窗口分区里完成。
- SMTP 授权码用系统级加密存储（Electron safeStorage）。

## 来源与致谢

`inject/` 下的自动化脚本起家于 Android 端「夜航小子·抖音续火花」APK 中解出的纯 DOM 脚本；本项目把它搬到抖音网页版，桥接层用 Electron 重写，脚本在桌面端持续维护适配。
